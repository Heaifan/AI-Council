# D3 · WEB_RELAY — 人工验收清单（A01..A10）

> **执行命令**：`node app/tests/run-browser.js`
> **预期结果**：总计 ≥54 项（D1: 7 + D2: 19 + D3: 25 + 测试页: 1 + JS错误: 2），全 PASS。

## A01 — 顶部标题与徽标中文化

1. 打开 `app/index.html`（双击或 file://）
2. 顶部标题应为「AI 顾问委员会 · 开发验证台」
3. 顶部徽标应为「人工网页中继」
4. **不得出现**「D2-F1 Integration Harness」「Developer Harness」

## A02 — 能力灯（6 个全亮，含 WebRelay）

1. 页面加载后能力灯行应显示 6 个灯：议事规则 / 会议运行时 / 会议存档 / 指令编译器 / 提示词渲染器 / 网页中继
2. 全部为 ✅（不再有红叉）
3. **WebRelay 灯必须为 ✅**（根因已修复：index.html 已装配全部 relay 脚本）

## A03 — 独立运行状态行

1. 能力灯下方应有独立的「当前状态」行
2. 初始文本：「当前状态：等待选择项目目录」
3. 选择目录后文本变化为「当前状态：已加载议事规则，等待创建会议」
4. 创建会议后文本变化为「当前状态：会议 XXX · 进行中」
5. **运行状态行与能力灯分开**：能力灯只表示模块是否装载，不表示是否已建会议

## A04 — 会议页空状态

1. 点击「会议」Tab
2. 应显示中文提示：「当前没有正在进行的会议。你可以创建模拟会议，或创建网页中继会议进行真实 AI 测试。」
3. 下方应有说明文字区分模拟会议与网页中继会议

## A05 — 创建网页中继会议

1. 选择项目目录（AI-Council 根目录）
2. 点击「会议」Tab
3. 点击「创建网页中继会议」按钮
4. 会议状态应显示「进行中」，阶段显示「opening」
5. 网页中继面板应显示提示「委员 agent-a1 走网页中继…」
6. 应出现「生成提示词（agent-a1）」按钮

## A06 — 提示词生成与选中

1. 点击「生成提示词（agent-a1）」
2. 应出现只读 textarea，内容为非空提示词（>100 字符）
3. 按钮文案应为「选中全部提示词」（**不得**是「复制 Prompt」）
4. 点击「选中全部提示词」后应提示「提示词已全部选中，请按 Ctrl+C 复制。」
5. textarea 内文字应被全选高亮

## A07 — 粘贴回答 → 校验 → 接受

1. 在「外部 AI 回答」框中粘贴一段有效回答（≥10 字符，≤20000 字符）
2. 点击「提交回答」
3. 校验状态应显示「通过」
4. 应显示 V01–V05 五条校验，全部 ✅
5. 中继状态应显示中文「校验通过」，内部状态行显示「内部状态：validated」
6. 应显示警告「注意：此回答尚未写入正式会议记录。」
7. 「接受为正式发言」按钮应可用
8. 点击「接受为正式发言」
9. 应提示「已接受为正式发言并写入会议记录。」

## A08 — 空响应拒绝与错误码

1. 创建新的网页中继会议
2. 生成提示词
3. 在回答框中**不输入任何内容**（留空）
4. 点击「提交回答」
5. 应显示错误提示，包含中文解释 + 「错误代码：EMPTY_RESPONSE」
6. 中继面板应回到待中继提示状态（agent-a1 仍待响应）

## A09 — 取消请求

1. 创建新的网页中继会议
2. 生成提示词
3. 点击「取消本次请求」
4. 应提示「已取消本次请求。会议本身不受影响。」
5. 中继面板应回到待中继提示状态

## A10 — 模拟会议回归（无回归）

1. 创建模拟会议（非中继）
2. 执行下一步（模拟）应正常推进
3. 步进至 Human Gate 时按钮应禁用
4. 人工点「结束会议」应走向终局
5. 编译器 Tab 在无会议 / 会议结束时应禁用并显示中文操作指引
